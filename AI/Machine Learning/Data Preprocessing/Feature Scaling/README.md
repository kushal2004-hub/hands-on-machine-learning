Feature Scaling (Standardization & Normalization)


📌 Project Overview
This project demonstrates Feature Scaling, a crucial preprocessing step in machine learning. It shows how Standardization and Normalization transform data to improve model performance.


📂 Dataset
Dataset contains numerical features
Used to demonstrate scaling techniques
Helps compare original vs scaled data


🧠 Techniques Used
Technique	Description
Standardization	Scales data to mean = 0 and std = 1
Normalization	Scales data to range [0, 1]


🔧 Key Steps
Data Loading: Load dataset
Data Inspection: Understand feature values
Standardization: Apply StandardScaler
Normalization: Apply MinMaxScaler
Comparison: Compare original vs scaled data


📊 Results
Method	Outcome
Standardization	Mean-centered data
Normalization	Values between 0 and 1
✅ Features successfully scaled for model readiness.


📈 Visualizations
Before vs after scaling comparison

Range transformation
