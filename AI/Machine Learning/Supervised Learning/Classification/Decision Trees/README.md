### Decision Tree Classification on Iris Dataset

### 📌 Project Overview

This project implements a Decision Tree classifier to perform supervised classification on the Iris dataset. The model learns decision rules from data and predicts flower species based on their features.

### 📂 Dataset: Iris Dataset (Scikit-learn)

Built-in dataset from Scikit-learn

Contains 150 samples with 4 numerical features

Three flower classes:

Setosa

Versicolor

Virginica

Target variable: Flower species

### 🧠 Model Architecture
Component	Description
Algorithm	Decision Tree Classifier
Learning Type	Supervised Learning
Splitting Criteria	Gini Index
Max Depth	5
Output	Flower Class

### 🔧 Key Steps

Dataset Loading: Load Iris dataset using sklearn

Data Inspection: Analyze structure and statistics

Feature Selection: Separate input and target

Train-Test Split: Split data (80/20)

Model Training: Train Decision Tree model

Prediction: Predict flower species

Evaluation: Measure accuracy and performance

Visualization: Plot decision tree
