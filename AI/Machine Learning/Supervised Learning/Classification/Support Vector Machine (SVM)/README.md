## Support Vector Machine (SVM) Classification on Iris Dataset

### 📌 Project Overview

This project implements a Support Vector Machine (SVM) classifier to perform supervised classification on the Iris dataset. The model separates classes by finding an optimal hyperplane and uses kernel methods to improve classification performance.

### 📂 Dataset: Iris Dataset (Scikit-learn)

Built-in dataset from Scikit-learn

Contains 150 samples with 4 numerical features

Three flower classes:

Setosa

Versicolor

Virginica

Target variable: Flower species

### 🧠 Model Architecture
Component	Description
Algorithm	Support Vector Machine
Learning Type	Supervised Learning
Kernel	RBF (Default)
Regularization (C)	1.0
Output	Flower Class

### 🔧 Key Steps

Dataset Loading: Load Iris dataset using sklearn

Data Inspection: Analyze feature structure

Train-Test Split: Split data (80/20)

Model Training: Train SVM model

Prediction: Predict flower species

Evaluation: Measure accuracy and performance

Kernel Comparison: Compare different kernels
