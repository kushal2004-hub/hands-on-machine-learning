## Random Forest Classification on Iris Dataset

### 📌 Project Overview

This project implements a Random Forest classifier to perform supervised classification on the Iris dataset. By combining multiple decision trees, the model improves accuracy and reduces overfitting.

### 📂 Dataset: Iris Dataset (Scikit-learn)

Built-in dataset from Scikit-learn

Contains 150 samples with 4 numerical features

Three flower classes:

Setosa

Versicolor

Virginica

Target variable: Flower species

### 🧠 Model Architecture
Component	Description
Algorithm	Random Forest Classifier
Learning Type	Supervised Learning
Base Models	Decision Trees
No. of Trees	100
Output	Flower Class

### 🔧 Key Steps

Dataset Loading: Load Iris dataset using sklearn

Data Inspection: Understand feature structure

Train-Test Split: Split data (80/20)

Model Training: Train Random Forest model

Prediction: Predict flower species

Evaluation: Measure accuracy and performance

Feature Importance: Analyze important features
