Gradient Boosting for Supervised Learning


📌 Project Overview
This project implements Gradient Boosting, an ensemble learning technique that builds models sequentially to improve prediction accuracy by correcting errors from previous models.

Used for supervised learning (classification/regression)
Data is split into training and testing sets
