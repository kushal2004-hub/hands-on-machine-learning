Hierarchical Clustering using Agglomerative Method


📌 Project Overview
This project demonstrates Hierarchical Clustering, an unsupervised learning technique used to group data into clusters based on similarity. The model builds a hierarchy of clusters and visualizes it using a dendrogram.


📂 Dataset
Synthetic dataset generated using Scikit-learn
Contains multiple clusters of data points
Used for clustering visualization and analysis


🧠 Model Architecture
Component	Description
Algorithm	Hierarchical Clustering
Type	Unsupervised Learning
Method	Agglomerative (Bottom-Up)
Distance Metric	Euclidean
Linkage Method	Ward


🔧 Key Steps
Dataset Creation: Generate sample data using sklearn
Distance Calculation: Compute distances between points
Dendrogram Plotting: Visualize cluster hierarchy
Model Training: Apply Agglomerative Clustering
Cluster Assignment: Group data into clusters
Visualization: Plot clustered data
