Apriori Algorithm for Association Rule Learning


📌 Project Overview
This project implements the Apriori algorithm, an unsupervised learning technique used to discover association rules and frequent itemsets in transactional data. It is widely used in market basket analysis to identify relationships between items.


📂 Dataset
Transactional dataset containing items purchased together
Data is preprocessed using one-hot encoding
Used to generate association rules


🧠 Model Architecture
Component	Description
Algorithm	Apriori
Learning Type	Unsupervised Learning
Output	Association Rules
Key Metrics	Support, Confidence, Lift


🔧 Key Steps
Data Loading: Load transactional dataset
Preprocessing: Convert data into one-hot encoded format
Frequent Itemsets: Apply Apriori algorithm
Rule Generation: Generate association rules
Evaluation: Analyze rules using support, confidence, and lift
Filtering: Select strong rules


📊 Results
Metric	Description
Support	Frequency of itemsets
Confidence	Probability of rule
Lift	Strength of association

✅ Meaningful relationships between items identified.
