## House Rent Data – Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project focuses on exploratory data analysis (EDA) of a house rent dataset to understand rental trends, customer preferences, and relationships between different features. The analysis helps in identifying important factors that influence house rent.

## 📂 Dataset: House Rent Dataset

Contains information about rental houses

Includes features such as:

BHK

Size

Area Type

City

Furnishing Status

Bathroom

Rent

Real-world housing data for analysis

## 🔍 Objectives

Understand the structure of the dataset

Identify missing values and inconsistencies

Analyze rent distribution

Explore relationships between features

Extract useful insights for future modeling

## 🧠 Concepts Covered
Topic	Description
Data Loading	Reading CSV files using Pandas
Data Cleaning	Handling missing and duplicate values
Data Exploration	Understanding columns and data types
Visualization	Plotting graphs using Matplotlib & Seaborn
Statistical Analysis	Mean, median, correlation, distribution
Feature Analysis	Studying effect on rent

## 🔧 Key Steps

Data Loading: Import dataset using Pandas

Initial Inspection: Use .head(), .info(), .describe()

Missing Values Check: Identify null values

Data Cleaning: Remove or handle unwanted data

Visualization: Plot histograms, boxplots, count plots

Correlation Analysis: Understand feature relationships

Insights: Summarize important findings
